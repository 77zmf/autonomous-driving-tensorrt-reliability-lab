# Security and safety

This repository is an educational and portfolio lab. It is not a production inference stack, is not safety certified, and must not be used to control a vehicle or make a release decision.

## Reporting a vulnerability

Do not open a public issue containing credentials, private data, internal paths, or exploit details. Contact the repository owner through their GitHub profile with a minimal, non-sensitive description first.

## Sensitive material

If sensitive material is committed accidentally:

1. stop sharing the affected revision;
2. rotate exposed credentials immediately;
3. remove the material from the current tree and repository history;
4. review derived artifacts for the same exposure;
5. document the incident without repeating the secret or private data.

Public experiments must use public models, public or synthetic data, and sanitized summaries. Employer/customer code, models, logs, road-test data, vehicle identifiers, calibration, maps, screenshots, internal URLs, and confidential measurements are out of scope.
