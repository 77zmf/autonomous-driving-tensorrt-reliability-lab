# Reviewed results

This directory is for small, reproducible, reviewed summaries only. A result must include:

- full git commit;
- experiment manifest;
- public model/data provenance and hashes;
- exact command;
- correctness oracle and tolerance;
- warm-up and measured iteration counts;
- p50/p90/p95/p99 plus mean/min/max;
- model-only and end-to-end timing separation;
- limitations and falsification criteria.

Raw captures belong under `artifacts/` or `results/raw/` and are ignored by git.
